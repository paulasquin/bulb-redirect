# bulb.paulasquin.com → bulb.tailb37496.ts.net

An easy name for the DSM of the NAS `bulb`. This repository only holds `bulb.paulasquin.com` on GitHub Pages (`CNAME`) and sends every page, path and query included, to `https://bulb.tailb37496.ts.net`, which answers on Paul's tailnet only (Tailscale serve, Let's Encrypt certificate). Nothing here exposes the NAS: off the tailnet the target does not resolve to anything reachable. `404.html` is a copy of `index.html` so that any path redirects.
